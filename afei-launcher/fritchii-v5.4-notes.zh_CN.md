Fritchii v5.4 改进了 AMD 显卡上的着色器准备。

- **AMD 现在会为整个游戏准备着色器。** 此前《时之笛》的 120,461 个着色器中，有 116,373 个会在 AMD 显卡上被跳过。它们在 NVIDIA 显卡上录制，两家的驱动处理动态逻辑运算的方式不同。Fritchii 现在会为 AMD 驱动转换这些着色器，首次进入新区域时也能用到预编译结果。感谢 koriko 提供用于定位问题的日志。
- **AMD 显卡会再经历一次完整的着色器准备。** 即使在 v5.x 中已经准备过，更新后也会再运行一次。八核 CPU 约需 15 分钟，完成后即可直接进入游戏。
- NVIDIA 显卡的行为保持原样。

### v5.3

- **AMD 默认关闭着色器库。** v5.2 的驱动识别未命中 AMD Windows 驱动，导致 RX 5000 和 6000 系列仍可能在加载着色器时崩溃。现在会正确应用默认设置。此前已手动关闭的设置会保留。
- **更新下载会自动重试。** 从下一次更新起，如果 GitHub 文件服务器返回 504 等错误，或连接中断，程序会再尝试几次。

### v5.2

- **GTX 10 系列及更早的显卡可以再次绘制原先不可见的几何体。** 这些显卡不支持网格着色器，因此改用计算着色器处理相应物体。个别植被或墙壁仍可能缺失或闪烁。此功能基于 zortos 的原型（Lichii #569、#642、#841）。
- **AMD 纹理解码修复。** 宽高与压缩块大小不对齐的纹理曾经写入其他纹理的内存，可能出现黑块、网格纹和 GPU 崩溃。修复来自 CheezerWheezer 的 AMD 分支。
- **AMD Windows 驱动默认关闭着色器库。** RX 5000 和 6000 系列此前可能在编译着色器库时崩溃。现在会自动关闭该功能，NVIDIA 显卡继续使用。
- **主页恢复完整右键菜单。** 可以打开模组数据位置、导出 RomFS、移除条目、验证完整性，或使用全局设置启动游戏。
- **长时间运行时可超过 Windows 内存预算。** 原先在城下町运行约半小时后可能崩溃。系统内存里的缓冲区现在可以像纹理一样超过 Windows 内存预算。修复也来自 CheezerWheezer 的 AMD 分支。

### v5.1

- 修复新尺寸对话框首次出现时，文字显示为其他纹理碎片的问题。
- 「帮助」菜单和主页游戏右键菜单加入「清理着色器缓存」，操作前会提示确认。下次启动时会重新准备着色器。
- 改善 AMD 显卡点击「启动游戏」后可能发生的崩溃，原问题在使用 v4 缓存的 RX 6600 上出现。暂时撤回 v5 对王家墓地红线的修改，因此 AMD 显卡可能再次显示那条线。
- 撤回 v5 中一项 GPU 小范围写入后的内存刷新调整，它可能让模拟器读到旧数据。
- 改善 4K 和缩放显示器的适配。窗口会按 Windows 的缩放设置调整，避免将 150% 误当成 200%，或将 125% 误当成 100%。
- 游戏设置窗口可调整尺寸，较长的页面可以滚动，方便使用「确定」和「应用」。

### v5 的主要改动

原作者在 Windows x64 上用 Ryzen 7 7800X3D 和 RTX 4080 测试了《时之笛》（0400486024DEC000）。许多场景可稳定在 60 帧，最重的场景（含水之神殿）也很少低于 45 帧。着色器准备完成后，原作者未遇到着色器卡顿。

#### 新功能

- **首次启动可一次性准备着色器。** 八核 CPU 约需 15 分钟。准备完成后，首次进入新区域的着色器停顿从约 0.7 秒缩短到 40–70 毫秒，加载也更快。显卡或驱动变化后会再次准备。基于 zortos 的预编译工作（Lichii #895、#896）。
- 新增石墨主题、主页、更新说明，以及「帮助 → 导出日志」。
- 将鼠标移到游戏画面顶部，可使用暂停、重新启动、停止、全屏及菜单。
- 「视图 → 性能浮层」新增帧率、帧时间、近期最低帧率和 60／30 帧参考线。加载时图表会留空。

#### 性能

- 改进渲染目标迁移、图像池、帧时钟和旧副本清理。原作者在城下町的测试中，每项修复约提高 3 帧，显存用量也从约 8.8 GB 降到 6.4 GB。
- 系统内存用量减少约 2.3 GB。
- Windows 11 内置更精确的游戏时钟，获得此前全局计时器注册表调整的效果。
- 着色器转换已移出 GPU 线程，并用新代码重新训练了配置文件引导优化。

#### 修复

- 空着色器缓存下，「按开始」提示、对话气泡和光照可正确显示。
- 修复个别游戏中物体会在整个会话里消失的问题（裁剪距离，Lichii #902）。
- 可用内存较少时继续使用 Fastmem，避免性能悄悄下降 20–25%（Lichii #645）。
- 减少着色器准备时的内存用量（#878），并修复罕见的通道死锁（#609）、模组目录不存在（#686）、Windows 长路径（#576）等问题。

#### 着色器缓存

缓存升级到版本 54，Fritchii 和 zortos 的构建可以共用。首次启动会复制一份旧缓存，《时之笛》约需额外 1.2 GB。旧的 `v52` 缓存会保留，供回退到 v4 时使用。

#### 已知事项

原作者未在 AMD 和 Intel 硬件上验证相关改动。如遇问题，报告中可附上显卡型号和「帮助 → 导出日志」生成的日志。
